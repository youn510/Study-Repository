# 암호화된 AI일기장 프로젝트 ( Secure AI Diary )

AI 감정 분석 기능과 데이터 암호화 기술이 결합된 보안 특화 일기장 서비스

- **백엔드:** Python(Flask)을 이용해 서버를 구축하고 회원가입/로그인 기능을 구현
- **AI:** 사용자가 쓴 일기의 감정을 분석해 주는 간단한 AI 모델(NLP) 활용
- **보안:** 사용자의 일기 내용을 암호화해서 DB에 저장하고, 로그인 보안을 강화

### 1단계: 기능 정의 (요구사항 명세)

- **핵심 기능:** 글쓰기, 감정 분석 결과 보기, 데이터 암호화 저장.
- **'회원가입 -> 로그인 -> 일기 쓰기 -> 저장'** 이 흐름만 완성한다는 생각으로 시작

### 2단계: 기술 스택 확정

- **언어:** Python
- **백엔드 프레임워크:** **Flask**
- **데이터베이스:** **SQLite** 
- **AI:** `Hugging Face`의 감정 분석 라이브러리

### 3단계: 환경 구축 및 "Hello World"

- Python 가상환경(`venv`)을 만들고 Flask 설치
- 브라우저에 "Hello World"가 뜨는 것을 확인

### 4단계: MVP(최소 기능 제품) 개발

1. 사용자가 입력한 텍스트를 DB에 저장하고 다시 화면에 띄우기
2. 사용자 로그인 기능 추가하기 (Session, Cookie 개념 공부)
3. 입력받은 텍스트를 AI 모델에 넣어 결과값 받아오기
4. **보안 추가:** DB에 저장할 때 평문이 아닌 암호화된 상태로 저장
